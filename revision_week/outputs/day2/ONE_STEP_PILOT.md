## 结论（按任务书口径）

- 16/16 步在系数 1.0 即被 Armijo 接受（接受率 16/16）；无 step_rejected、无预算触发。
- **实际目标下降与真实参数误差分开报告**：全部 16 步两个量都改善，但二者不保证同时改善，此处仅为本试验的观测。
- **曲率区分度**：SAEPS-GN/SO/ORACLE 的原始步长（0.15–0.38）全部被共同信赖半径 0.1 截断到同一步长，三个方法的试验点、实际下降与参数误差逐位相同——按任务书规则，**这组试验缺少曲率区分度**；不得据此宣称 SO 与 oracle 等效，也未现场调整半径。
- 被截断组数：4/4 分支（GN/SO/ORACLE 同步长）。
- RAW（G_ll，未约化曲率）未被截断（步长 0.007–0.015），其目标下降与参数误差改善显著小于 GN 型曲率组——曲率选择确实改变一步更新质量；这是 RAW vs GN 型曲率的功能性差异，不是 SO 的优越性证明。
- 二次模型质量诊断（未被截断比较的唯一可分辨量）：actual/predicted 中位数 1.02；SO 的 predicted decrease 一致地比 GN 更接近 oracle 与实际值（模型更准），但试验结果本身不可分辨。
- 全部 actual > predicted（1.01–2.0）：λ 二次模型系统性偏保守，无不一致警报。
- 计算成本：17.5s 墙钟（4 次公共起点求解 + 16 次候选内层求解，均在 5 min/次上限内）；根中心精化 0 次（两根中心均直接通过资格门，未启用预算精化）。
- 本试验为**开发性功能验证**：只支持"曲率能实际参与一次参数更新并带来可解释的目标下降"，
  不构成统计确认、全局反演或训练加速证据。
